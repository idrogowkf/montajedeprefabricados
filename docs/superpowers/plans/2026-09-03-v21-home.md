# Home V2.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reproduce the approved V2.1 Home in maintainable Next.js components with a production-grade guided pre-study flow.

**Architecture:** Keep the page server-rendered and isolate interaction in three client islands. Submit sanitized project data to a new Resend endpoint and upload optional documents directly to Vercel Blob through a server-authorized client flow.

**Tech Stack:** Next.js 14 App Router, React 18, TypeScript, Tailwind/CSS, Resend, Vercel Blob.

**Spec:** `docs/superpowers/specs/2026-09-03-v21-home-design.md`

## Global Constraints

- `montaje-prefabricados-v2.1.html` is the visual source of truth.
- Preserve existing SEO, routes and APIs.
- Use only the MONTAJE PREFABRICADO identity.
- Never invent projects, clients, certifications or performance claims.
- Keep secrets server-side and list only variable names in `.env.example`.
