# Catálogo de aprobación de 720 productos

## Objetivo

Crear un PDF de revisión, separado de la tienda pública, con 720 referencias reales y verificables para decidir cuáles se incorporarán después al marketplace.

## Alcance

El documento contendrá seis secciones, en este orden, con 120 referencias únicas por sección: hormigón, acero, madera, PVC, trabajos en altura y EPI. Una referencia aparecerá una sola vez en su sección principal; las aplicaciones secundarias se indicarán con etiquetas.

## Regla de admisión

Cada referencia debe tener fabricante, nombre comercial, código o referencia, aplicación, país de origen del fabricante o proveedor, URL oficial o de distribuidor autorizado, al menos una imagen identificable y un PDF técnico oficial. No se admitirán nombres genéricos, referencias inventadas, imágenes de otro modelo ni páginas comerciales usadas como si fueran fichas técnicas.

Una referencia podrá compartir un PDF de catálogo con otras referencias del mismo fabricante únicamente cuando el PDF identifique inequívocamente el modelo o código incluido. Las variantes de medida cuentan como una sola familia de producto salvo que tengan códigos y prestaciones materialmente distintas.

## Fuentes

Se priorizarán fabricantes y documentación primaria. Se aceptarán distribuidores autorizados para disponibilidad, imagen complementaria u origen comercial, pero nunca para sustituir la identidad técnica del fabricante. La selección podrá incluir España, Unión Europea, Reino Unido, Estados Unidos y otros mercados siempre que el producto sea técnicamente relevante y su documentación sea comprobable.

## Estructura de datos

Cada candidato tendrá: id estable, sección principal, etiquetas de utilidad, fabricante, referencia, nombre, descripción breve, aplicaciones, proveedor, país, URL de producto, URL directa del PDF, URL de imagen, fecha de verificación y estado de todas las comprobaciones HTTP.

## Documento

El PDF usará la identidad gráfica negra, blanca y roja de Montaje Prefabricado. Tendrá portada, índice, separador por sección y cuatro fichas por página en A4 apaisado. Cada ficha mostrará imagen, fabricante, referencia, descripción, aplicación, origen y enlaces clicables al producto y a la ficha técnica. El pie incluirá sección, fecha y paginación.

## Control de calidad

Antes de generar el PDF se exigirán exactamente 120 referencias válidas por sección y 720 ids y pares fabricante-referencia únicos. Todas las imágenes y PDFs deberán responder correctamente y concordar con la referencia. Después se comprobarán el texto extraído, el número de fichas, los enlaces y una representación PNG de todas las páginas para detectar recortes, solapamientos o imágenes rotas.

## Exclusiones

Este trabajo no publica productos, precios ni proveedores en la tienda; tampoco inventa costes o márgenes. La importación al marketplace se realizará solo después de la revisión del PDF por el usuario.
